# Profil-Arbeitsbereich und Programm-Hintergründe · .178

Der [Entwurf](../images/rendering-evidence/profile-concept-3429178.png) wurde mit
der eingebauten Bildgenerierung aus der vorhandenen OHC-Dunkelansicht erstellt.
Er ist eine Illustration, keine Messung oder Zusage fiktiver gespeicherter Werte.
Die Umsetzung zeigt nur echte gespeicherte Bereiche. Profile bleibt ein eigener
bestehender Navigationseintrag; die illustrative Seitenleistenposition wird
nicht übernommen. Die [dunkle](../images/rendering-evidence/profiles-dark-3429178.png)
und [helle](../images/rendering-evidence/profiles-light-3429178.png) Qt-Darstellung
sowie die schmale Variante sind isolierte Renderings mit synthetischen Profilen.

Verwendeter Bildprompt (eingebaute Bildgenerierung, kein CLI-Aufruf):

> Use case: ui-mockup. Create a high-fidelity implementable German desktop UI concept for the
> Profiles page of Open Hardware Control. The attached screenshot is a REFERENCE for the existing
> shell, dark slate palette, cyan accent, typography and rounded panels. Preserve that app's
> recognizable design language, existing left navigation, logo area and the ability to have a
> restrained animated background. Replace the main page with an elegant compact Profiles
> workspace. At top title 'Profile', subtitle 'Deine Einstellungen. Ein Profil.' and a '+ Neues
> Profil' action. Small startup banner with clock icon 'Profil beim Start' and selector 'Zuletzt
> verwendetes Profil'. Main layout: left 30% profile library, search 'Profile durchsuchen …',
> filter pills 'Alle', 'Eigene', 'Standard', vertical compact rounded profile cards named
> 'Gaming', 'Leise Nacht', 'Ausbalanciert', 'Leistung'; each has an original abstract icon and
> subtle section badges. Selected Gaming card cyan border. Right 70% roomy selected profile
> overview titled 'Gaming', short description, badges 'Eigenes Profil', 'Gesamt', a clear primary
> 'Profil anwenden' action and secondary 'Bearbeiten' and 'Mehr ⋯'. Below are five beautiful
> compact summary tiles for 'Kühlung', 'Grafikkarte', 'RGB', 'LCD', 'Design & Anzeige', with
> original thin-line icons, small informative saved-setting summaries, cyan-green colour swatches
> on RGB, a tiny abstract green code-rain illustration on LCD, a very small fan curve sketch on
> cooling. Do not include fake live measured temperatures. At bottom collapsed rows 'Technische
> Details' and 'Import, Export & Sicherung'. No large tables, no JSON/code text, no cluttered
> nested lists. Crisp aligned layout, readable German, realistic Qt desktop interface, premium
> but restrained, no browser chrome, no new unrelated features. Landscape screenshot
> 1440x1000-ish. Label subtly 'ENTWURF' so it is clearly a proposed design.

Videos werden vollständig durch die eigenen Offline-Renderer unter tools
berechnet; keine SignalRGB-Dateien, fremden Clips oder Downloads. Die fünf neuen
Studien verwenden periodische Lichtfelder, Oberflächennormalen, Nebel und Kaustik.
`src/assets/app-backgrounds/render-evidence.json` dokumentiert den berechneten
Schleifenübergang. Matrix-Varianten vergrößern Glyphen und Raster gemeinsam;
das Seitenverhältnis und die 1600×720-Auflösung bleiben gleich.

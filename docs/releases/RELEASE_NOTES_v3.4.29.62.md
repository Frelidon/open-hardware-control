# Open Hardware Control 3.4.29.62 INTERN

Display Effects 1.6 adds fifteen locally bundled, silent 1600×720 animations:
five Space & Earth, five Landscape & sky and five Water & underwater designs.
Every chosen excerpt was manually reviewed without visible people. Source title
cards and end logos are outside the packaged excerpts; the rejected Saturn-tech,
artificial 3D galaxy fly-through and Grand Canyon people videos are absent.

The library now has four local filters: Abstract, Space & Earth, Landscape &
sky, and Water & underwater. Creator, original source and exact license remain
clickable for every design. The original five abstract designs and their four
colour variants remain available, producing 35 bundled effect choices in total.

Levita Studio adds nine editable Layer-2 themes. Space Console, Orbital Reticle,
Navigator Grid, Ambient Glow and Clean Telemetry each use one documented CC0
component from an official Kenney pack. OHC Orbit, OHC Aqua Pulse, OHC Horizon
Glass and OHC Split Core are original project artwork. Every layout contains
live metric blocks and keeps the physical right-notch area safe.

The existing strict package-root checks, local preview, profile-start staging,
bounded video-ticker recovery and sole TRCC hardware writer are unchanged. The
new library has no runtime network access. German, English, Spanish and French
contain the same 1,151 stable messages.

The supplied cooling log was diagnosed separately: the audible rise followed a
real CPU increase to 73.1 °C and the configured 9800X3D curve, without a
100-percent fallback or missing sensor. The current card label “Automatik aus”
describes state rather than action and can therefore be misunderstood; fan
control code was not changed as part of this display-focused build.

No GitHub push, tag or public release was created.

# Open Hardware Control 3.4.29.59 INTERN

This internal version implements the approved compact shell: OHC client-side
window controls, collapsing LCD child navigation, compact RGB suggestions and
favorites, four additional original effects, and a 30-entry schematic PC case
catalog with local user profiles. Thermaltake Retro 360 TG is the exact default
reference and links to both the official manual and the owner-supplied Amazon
page. Manufacturer artwork is not bundled.

Window movement and resizing are delegated to Qt/KWin for Wayland/X11. Existing
tray close/autostart suppression and every hardware ownership boundary remain
unchanged. No GitHub push, tag or public release was created.

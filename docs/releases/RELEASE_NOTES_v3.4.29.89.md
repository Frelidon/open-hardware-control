# Open Hardware Control 3.4.29.89 INTERN

- Smooth explicitly routed GPU-strip spinner/comet motion with wider fronts/
  tails, count-aware rate and bounded temporal/area sampling. Open ends fade
  rather than treating LED 30 and LED 1 as physical neighbors.
- GPU setup adds "GPU und Halterung synchronisieren". The default-on option
  uses the support block’s explicit existing ARGB assignment. Exactly one
  selected, conflict-free GPU/header pair shares GPU effect, time and normalized
  progress. GPU 30 and support 12 remain independent physical lengths.
  Missing, ambiguous, unselected, blocked or ring partners stay separate.
- Other controller headers, native GPU effects, physical LED counts, PWM and
  true single-pixel tests are unchanged. Do not add a writer or raise the
  existing 25-Hz target. Paired nonmoving effects retain intentional flashes.
- Start diagnostics distinguish physical declared count and shared clock count,
  kernel widths, software cycles/rate and absent physical readback.
- Save synchronization only on explicit setup confirmation; cancellation is
  read-only. Complete private packages preserve the setting. RGB Studio 1.12,
  1,448 complete DE/EN/ES/FR messages; carry all .88 improvements.

Internal local RPM and complete archives only. No installation, firmware/
backend change, live hardware operation or public publishing. Optical motion
must be checked on the owner’s GPU/support; tests cannot prove physical FPS.

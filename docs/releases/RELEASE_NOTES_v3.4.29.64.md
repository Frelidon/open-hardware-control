# Open Hardware Control 3.4.29.64 INTERN

Nebula Drift is once again a genuine two-layer design. Its original nebula
artwork retains the earlier faint RGBA transparency, allowing the selected
Layer-1 video, landscape and movement to remain visible underneath. The broad
opaque cards introduced in 3.4.29.63 have been removed.

Only the live values now receive compact dark readability pills with restrained
cyan, violet or white outlines. Three editable presets ship with the program:

- **Nebula Drift · Minimal** — clock plus CPU and GPU temperatures.
- **Nebula Drift · System** — clock, CPU temperature, GPU temperature and RAM.
- **Nebula Drift · Leistung** — clock, CPU/GPU load, temperature and clock rate,
  plus RAM.

The gallery thumbnails composite the real transparent output over a bundled
mountain landscape so the intended video-plus-artwork-plus-values stack is
visible before applying the design. Regression coverage verifies real alpha,
all three discovered themes and three distinct metric sets.

Display transfer, the single-owner TRCC command queue, profile staging, cooling
curves, calibration, firmware return and every hardware-write path are
unchanged. No GitHub push, tag or public release was created.

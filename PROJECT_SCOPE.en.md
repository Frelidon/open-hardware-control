# Project scope – Open Hardware Control 3.4.23 INTERNAL

Version 3.4.23 extends the existing Kraken/RGB/OpenLinkHub hub with safety-gated motherboard fan control through Linux hwmon/NCT6687. PWM channels are automatically controlled only after physical calibration. RGB Studio also exposes the ENE-DRAM cold-start reclaim and can rerun it manually.

Open Hardware Control is the shared Linux interface for supported hardware modules.

It contains the complete NZXT Kraken module from 2.9.23 and the first safe Corsair/OpenLinkHub adapter. Future device families are intended to remain separate modules in the hierarchical navigation.

The OpenLinkHub module reads service state, devices, profiles and telemetry. Allow-listed documented controls added in version 3.0.4 remain available for cooling, RGB/LCD, mice, keyboards and headsets. Version 3.0.9 lets reported mouse buttons open a direct assignment editor and adds a bounded, window-local keyboard macro recorder. Buttons without a safely reported index, complex macro editing, the full RGB editor and new LCD media remain in the local dashboard.

Version 3.0.9 also adds a global Celsius/Fahrenheit display setting and independent label/value styling for generated LCD designs. Cooling data remains stored in Celsius. The original NZXT liquid-temperature screen restore from 3.0.7, the five-second delayed LCD profile startup from 3.0.6 and CPU-temperature curves from 3.0.5 remain active.

Version 3.4.0 added the automatically managed windowless RGB engine, device tiles, groups, ENE DRAM de-duplication, topology-safe NZXT effects and complete RGB reset. Version 3.4.1 replaced unsafe bundled CLI options with serialized single-device transactions, preserved selection/group state across asynchronous discovery, provided reported native fallbacks and added an editable PC diagram. Version 3.4.2 fixed the early RGB-preview startup failure and added private automatic lifecycle/crash logs. Version 3.4.3 quarantined individual devices that make OpenRGB itself abort in `ApplyOptions`. Version 3.4.4 closed the reset/engine race, folded fully mirrored inventories and replaced the position form with a draggable Thermaltake PC view. Version 3.4.5 bypasses the confirmed CLI abort for Direct devices through an original loopback SDK writer, preserves RGB-page scroll position and completes the editable twelve-fan layout. Version 3.4.6 separates OHC effects from GPU/hardware-mode selection, prepares Direct mode only once per device, continues after per-device failures and makes selection, control path and result status visible. Version 3.4.7 negotiates OpenRGB SDK revisions 4/5, removes unsupported NZXT 2023 effect aliases and blocks every second OHC process before any hardware initialization. Version 3.4.8 confirms server mode and color-buffer state through readback, blocks separately running OpenRGB processes and coalesces a full NZXT selection through `sync`. Version 3.4.9 configures empty resizable motherboard/hub zones through the documented SDK command, persists `fans/devices × LEDs`, and treats missing zone sizes without quarantine. Version 3.4.10 sends a complete device frame on every write, adds a one-time per-zone fallback, 24-LED Interstellar V2 presets and ckb-next conflict diagnostics. Version 3.4.11 keeps one local SDK connection open for animations, writes combined multi-device frames, and adds a guided setup wizard with visual tests. Version 3.4.12 added sortable Kraken channels, the animated design gallery, and LCD layers. Version 3.4.13 makes the gallery directly actionable and adds safe RGB ownership recovery. Version 3.4.14 fixes the NZXT alternating and OpenRGB self-detection loops and records device errors in RGB Studio. Version 3.4.15 adds mode colors, sortable page sections, and the configurable hardware dashboard. Version 3.4.16 adds serialized speed application, exact frame acknowledgement, and robust automatic inventory rechecks. 3.4.21/3.4.22 stabilize USB/RGB coordination, LCD design switching and CPU curves. 3.4.22.1 adds the ENE-DRAM cold-start reclaim. 3.4.23 adds calibration-gated motherboard/case fan curves through Linux hwmon/NCT6687 plus manual ENE reinitialization. OpenRGB stays separately installed and runs as a private child process; its source and Effects Plugin assets are not embedded.

Version 3.2.0 adds Windows-8/8.1-inspired local tiles and Charms, original free OHC icon/cursor themes, selectable backups with safe export/import and a Breeze Light emergency fallback to the existing reversible KDE Plasma layouts. In 3.3.0 this entire area became explicitly experimental, disabled by default and hidden from navigation. Optional desktop packages never block hardware control. It downloads no third-party themes, ships no proprietary Microsoft or Apple assets and leaves other desktop environments untouched.

Open Radeon Control Center remains separate. Firmware updates, GPU fan control, general motherboard/voltage/clock tuning and untested direct USB/register writes are out of scope. The 3.4.23 motherboard feature is deliberately limited to detected, writable and physically confirmed hwmon PWM channels.

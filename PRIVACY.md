# Privacy

Open Hardware Control does not include telemetry, advertising, analytics or an automatic cloud service.

The installed application does not call ChatGPT or the OpenAI API. External links in the About page open only after user action.

Diagnostic reports are generated locally and are not uploaded automatically. The diagnostic tool attempts to redact usernames, home-directory names, hostnames, machine IDs, boot IDs and device serial numbers. Users should still review every report before sharing it publicly.

The in-app action log is intended for troubleshooting. It does not record passwords or character-by-character keyboard input. The visible log is capped at 10,000 characters and removes the oldest complete lines first. Exported logs should still be reviewed before publication.

The optional KDE desktop-design module performs no network request. It stores timestamped configuration backups only in the current user's state directory. These backups are never uploaded automatically.

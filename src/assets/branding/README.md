# Open Hardware Control branding

- `open-hardware-control-logo.png` is the full user-provided Open Hardware Control logo used in the application rail.
- `open-hardware-control-icon.png` is the text-free, transparent compact application icon derived from that supplied logo with OpenAI ImageGen.
- `icons/` contains deterministic downscaled PNG variants for Linux desktop, taskbar and tray use.

These assets belong to the Open Hardware Control project branding. They are not manufacturer product assets and must not be presented as an endorsement by any hardware vendor or Linux project.

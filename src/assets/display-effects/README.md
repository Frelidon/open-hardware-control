# Bundled display-effect media

These videos are edited 1600x720, 24-FPS, silent H.264 derivatives for the
Thermalright Levita display. The five abstract third-party sources are shipped
in four OHC colour variants. The fifteen nature/space sources use one faithful
`original` variant. The original OHC media include eight directional Light Bands,
an animated Spectrum Ring, Prism Drift, Twin Wyrm Orbit, Neon Particle Garden,
and Circuit Chase. The paired JPEG is a local preview of the
matching video. OHC adds the selected live Layer-2 layout at runtime. All
selected third-party excerpts were manually reviewed to exclude visible people,
source title cards and technical overlays.

Light Bands .95 regeneration uses actual 4800×2160 Qt source frames reduced to
native 1600×720, H.264 CRF 10 and JPEG 98. Permanent cold borders and narrow idle
centre highlights are removed; proportional glow avoids a faint hard cutoff.
All eight four-second/24-FPS loops have passed complete decoding checks.

# GPU artwork

`gpu-family-amd-red.png` and `gpu-family-nvidia-green.png` are original,
unbranded transparent illustrations generated for Open Hardware Control with
OpenAI ImageGen on 22 September 2026. They intentionally contain no product
logo, wordmark or copied manufacturer card design.

Generation direction: isolated modern desktop graphics card, transparent
background, realistic dark metal, no text or logos, clean front three-quarter
view, with restrained red/cyan or green accent lighting. The app treats both
images as generic presentation assets; model names never select tuning limits.

Users may replace the presentation with their own transparent PNG/WebP. OHC
normalizes a private copy and never modifies or deletes the imported source.

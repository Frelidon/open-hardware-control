# OHC Levita designs

These project assets were created by the OHC project owner together with OpenAI tools on 31 August, 2 September and 8 September 2026. The final files were generated or center-cropped/resampled locally to the exact Thermalright Levita canvas of 1600×720 pixels. They contain no copied TRCC catalog, Thermalright media or other manufacturer artwork.

- `ohc-carbon-blue.png` — prompt mode: new raster generation; dark woven carbon fibre, electric-blue technical edges, quiet right cutout area, no text/logos.
- `ohc-titanium-blue.png` — prompt mode: new raster generation; brushed titanium/gunmetal panels, restrained blue edge lighting, quiet right cutout area, no text/logos.
- `ohc-plasma-circuit.png` — prompt mode: new raster generation; midnight cyan/violet plasma circuit grid, dark sensor-overlay space, quiet right cutout area, no text/logos.
- `ohc-ai-neon-corridor.png` — original AI-generated blue science-fiction corridor.
- `ohc-ai-orbital-observatory.png` — original AI-generated blue/violet orbital observation room.
- `ohc-ai-neon-city.png` — original AI-generated violet futuristic city corridor.
- `ohc-ai-azure-reactor.png` — original AI-generated bright-blue reactor room.
- `ohc-ai-deep-space-command.png` — original AI-generated deep-space control deck.
- `ohc-ai-quantum-portal.png` — original AI-generated blue/violet portal hangar.
- `ohc-ai-crystal-core.png` — original AI-generated crystalline energy chamber.
- `ohc-ai-command-deck.png` — original AI-generated dark command deck.
- `ohc-ai-quantum-voyage-30s.mp4` — one 30.016-second H.264/AAC edition of the project owner's original AI animation, normalized to 1600×720. Exact local duplicates and a larger duplicate export were deliberately excluded.
- `ohc-3d-orbital-ring-10s.mp4` — seamless 10-second orbital-gate loop with a planet, survey craft and rotating station geometry.
- `ohc-3d-neon-apex-10s.mp4` — seamless 10-second futuristic sports-car turntable with a cyan/magenta grid and illuminated body details.
- `ohc-3d-quantum-core-10s.mp4` — seamless 10-second reactor loop with a pulsing core, counter-rotating energy rings and orbiting control pods.

The complete generation prompts and original generated files remain in the associated local Codex task history. The three 3D loops are reproducible with `tools/render_levita_loops.py`; their geometry, materials and motion are project-owned and contain no manufacturer models, logos or stock media.

Thirteen additional transparent Layer-2 layouts are reproducible with
`tools/render_levita_overlays.py`. `ohc-orbit`, `ohc-aqua-pulse`,
`ohc-horizon-glass`, `ohc-split-core`, `ohc-spectrum-ring`,
`ohc-neon-double-arc`, `ohc-prism-segments` and `ohc-aurora-radar` are original
OHC artwork. The four colourful layouts use only the general idea of rainbow
telemetry geometry and contain no copied product outline, logo or video frame.
The other five use only the named CC0 component documented in their own README from the
official Kenney UI Pack: Sci-Fi, Crosshair Pack, Minimap Pack, Light Masks or
UI Pack. Kenney permits commercial and non-commercial reuse under CC0 1.0:
https://kenney.nl/support

The same renderer preserves the original faint, transparent Nebula Drift source
as `ohc-nebula-drift/source-overlay.png`. It produces the three System, Minimal
and Performance variants and adds small dark pills only behind their live
values, so the selected Layer-1 video and its mountain or landscape remain
visible. Its selective `--theme` mode can
rebuild only the project-owned styles; `--preview-only` refreshes previews from
the existing transparent overlays without requiring the external CC0 sources.
Orbit, Aqua Pulse, Horizon Glass and Split Core deliberately use different
orbital, wave, glass-bar and angular split geometries.

The four colourful layouts also include original, seamless six-second
glow/particle loops generated by `tools/render_levita_motion.py`. OHC blends a
selected loop locally with Layer 1 and keeps the live text blocks in the
editable upper layer; no repeated USB mask writes or third-party video is used.

Runtime packaging includes only the final assets and audited layout
directories. Manufacturer catalog backups and imported TRCC media are outside
this repository and must never be added to a release.

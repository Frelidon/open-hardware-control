# OHC Neon Double Arc

Bundled 1600×720 Layer-2 theme for the Thermalright Levita display.

Artwork and layout: original Open Hardware Control design, GPL-3.0-or-later.

`motion.mp4` is the original six-second OHC glow/particle loop generated by
`tools/render_levita_motion.py`; it is used only as optional Layer-2 decoration.

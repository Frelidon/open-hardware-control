# Setup features 1.0

Defines the platform-aware feature catalog shown near the start of the common
Linux/Windows first-run assistant. Selection is settings-only: hovering and
preview animation never probes or writes hardware. Unavailable features remain
visible with a reason but cannot be enabled. A missing saved selection means
all platform-default features, preserving upgrades from older releases.
The hover explanation fades within a fixed reserved area, so provider/authority
controls below the feature grid never move under the pointer.

# Fan mapping 1.0

`runtime.py` owns explicit disconnected-channel choices, wizard test cleanup and
short driver leases for bounded 120-second chassis-only stop tests. No channel
is inferred absent from zero RPM. Existing mainboard writer/owner/calibration
APIs remain authoritative. Disconnected profiles retain curves but cannot be
activated until explicitly re-enabled and calibrated. `lighting.py` temporarily
owns the existing RGB preview scope and restores only the unchanged saved design.
